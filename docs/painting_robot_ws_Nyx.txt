sudo dmesg | grep -iE "ttyUSB|ttyACM"

That shows every serial adapter and which tty it got. But for your multi-device setup, the more useful command is:

ls -l /dev/serial/by-id/

This lists every USB-serial device by a stable unique id (chip + serial number) and shows which ttyUSB*/ttyACM* each maps to — so you can tell which adapter is the BMS vs lidar vs ultrasound at a glance, not just anonymous port numbers.

Also handy:

ls -l /dev/serial/by-path/    # by physical USB port location

For live watching (plug/unplug to identify a specific device):

sudo dmesg -w
